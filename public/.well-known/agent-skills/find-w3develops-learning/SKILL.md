# Find learning opportunities on w3Develops

Use this skill for public link discovery. The site's [content-use policy](https://w3develops.org/robots.txt) allows search and opts out of AI input and training. Return links as navigation results; do not treat this skill as permission to ingest site content for other purposes.

1. Select the public directory that matches the person's goal:
   - [Study groups](https://w3develops.org/studygroups) for learning a topic together.
   - [Group projects](https://w3develops.org/groupprojects) for building an application with a team.
   - [Book clubs](https://w3develops.org/book-clubs) for reading and discussing a book.
2. Check the directory and the specific public listing for the requested topic or project. Verify the title and link. An in-progress or visible listing does not establish availability, an open seat, or that someone can join. Do not infer dates or member eligibility.
3. Give the best verified public link and a next navigation step. For general onboarding, use the [quickstart](https://w3develops.org/docs/quickstart), the [study groups and book clubs guide](https://w3develops.org/docs/guides/study-groups), or the [group and solo projects guide](https://w3develops.org/docs/guides/group-projects).
4. If there is no verified match, say so and link to the relevant directory rather than inventing a listing.

Do not sign in, make account changes, post, join, or request to join on someone's behalf. Use only public pages; do not collect member information.
