A study group is a small group learning the same thing, like JavaScript or system design. Book clubs work the same way around one book.

## Join or start one

- **Find a group:** open [Study Groups](/studygroups) or [Book Clubs](/book-clubs) and search by name or topic. Start with the **New** section. An in-progress group only accepts new members if it is marked **Open to join anytime**. A full group cannot accept new members.
- **Join:** [sign in](/login) or [create a free account](/signup), then return to the group page and select **Join Group** or **Join Club**, if available. If you signed up with email and password, verify your address first. If none are open, browse other topics or start one.
- **Start:** select **Create**, give it a name, a topic and a short description, and set a meeting time if you have one.

## Inside a group

- **Check-ins:** post daily or weekly updates on what you did. Members of groups with a set time get a reminder before meetings.
- **Tasks:** a shared to-do list. Everyone in the group can add and tick off tasks; see all of yours on [My tasks](https://w3develops.org/account/my-tasks).
- **Leaving:** you can leave any time from the group page.

Running one? Follow the [study group workflow](/docs/guides/running-a-study-group) and pick a [curriculum template](/docs/guides/curriculum-templates).
